# Dataset de demostración

## Seoul Bike Sharing Demand

El archivo `SeoulBikeData.csv` contiene el número de bicicletas públicas alquiladas
por hora en Seúl y variables meteorológicas asociadas.

- Registros: 8.760
- Variables: 14
- Variables numéricas: 10
- Periodo: diciembre de 2017 a noviembre de 2018
- Fuente: UCI Machine Learning Repository
- Licencia: Creative Commons Attribution 4.0 (CC BY 4.0)
- DOI: https://doi.org/10.24432/C5F62R
- Página oficial: https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand

Los nombres de dos columnas con el símbolo de grados se normalizaron a texto ASCII
(`Temperature_C` y `Dew point temperature_C`) para evitar problemas de codificación.
Los registros y sus valores no fueron modificados.

Antes de entregar, el grupo debe confirmar con el docente que ningún otro grupo haya
registrado este mismo dataset. La aplicación no depende de este archivo y puede cargar
otro CSV o Excel sin cambiar el código.
